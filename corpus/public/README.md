# 公开语料材料

`manifest.json` 只列出有公开上游和固定提交的项目。`expected/` 与 `expected-links/` 是对相应固定版本编写的标注，不包含上游项目源码；许可标为“未知”的项目须核实后再下载或分发。

用户提供的本地项目及快照不属于此目录，也不应加入版本控制。原始本地清单、离线快照和本机产生的评分结果均不作为公开材料。

`npm run corpus` 对已取得的公开样本重新分析并生成 A–H 评分，同时执行目录发现检查。每个样本的固定版本、答案和依据文件都经过哈希校验；公开基线是原有基线的子集，不通过改变答案提高分数。两项许可证尚未核实的样本默认跳过，不计为通过。目录发现目前核对结构，但尚未核对完整评分哈希，因此只能标记为部分验证。

`npm run corpus:prepare-public` 从清单中的公开上游获取许可证已核实的固定提交，并核对已冻结标注引用的证据文件哈希；来源或许可证未核实时不自动下载。`npm run corpus:prepare-public -- --check-only` 只核对已有副本，缺失时跳过。默认目录是项目的受控缓存；可用 `CODELEADER_CORPUS` 指定 D 盘已有目录。不会运行这些项目的构建或应用，也不会覆盖已有修改。

私有语料默认不参与本次分析；缺失时显示跳过。若本地提供私有历史评分，表格只显示汇总数字，并标明它不是本次重新分析的结果。`npm run corpus:public-scorecard` 只整理已有结果，不重新分析。词语检查可读取可选的本地私有清单，清单缺失时跳过。
