# 界面层级与设计令牌

## U8c 缩放文字

画布变换产生时同步更新画布缩放变量；文字尺寸从该值计算，不依赖点击或 React 重新渲染。层级阈值及 8% 回差集中在 `adaptive-look.json`：约 0.78 开始收起模块叶子，约 0.68 转成应用摘要，约 0.34 转成概览。后两档沿用已有药丸和图标切换阈值；实际可读性和重叠仍以真实窗口测量为准。

## U9d 对话框

模态对话框使用同一外壳：遮罩、固定标题和操作区、可滚动的内容区，以及按视口留边的高度上限。打开后焦点进入窗口，Tab 在窗口内循环，Esc 关闭并恢复原焦点。主操作占整行，次要操作并列；按钮文字不换行。停靠的检查面板目前尚未全部迁移，必须在覆盖检查中如实列出，不能按已完成处理。

## U9c 阅读起点与提示

详情中的起点优先列出有数据访问关系的入口，其次比较可达的项目内调用和数据访问位置数、前端已对上调用数；只读仅用于这些数相同时，再以入口身份的稳定哈希决定顺序。一个调用位置的语义结果和规则结果只算一个步骤；入口本身算一步。这是静态结构的阅读顺序，不表示实际运行次数或时序。只有通过未唯一确定或有条件的关系才能到达资源时，明确显示“可能访问”。存在数据访问入口时只推荐这些入口，不足三条不以其他入口凑数；没有时才回退到其他入口。最多三条沿用 `orientation.recommendedLimit`：让第一屏能比较几条路径，而不重复完整入口列表。当前视图提示的计数口径和保守边界见 `docs/view-issue-metrics.md`，此段覆盖下文 U9 的旧排序。

## U9b 入口和可读性

顶部保留一条工具栏：左侧项目与视图，右侧帮助、未对上数量、搜索和“打开真实页面”。视图解释在帮助、标签提示和首次进入时的短暂标题中呈现，不保留第二条常驻栏；画布右下放图例与视角控制。首次导览固定画布左下并尽量与前端卡对齐，标记挂在可操作对象内部。缺少地址时仍能打开入口弹层，只展示从前端文件读出的启动命令和端口依据；未知地址由用户填写，启动仍需原有确认。

间距、颜色、按钮高度、导览宽度和显示时间使用 `ui-tokens.json`。中文及说明文字目标至少 12px，纯数字、快捷键和等宽徽标允许 11px；文本与实际背景目标对比度至少 4.5:1。Inter 和 JetBrains Mono 随应用提供，中文回退系统字体；图中文字缩放不改变原始数据。执行 `npm run check:orientation` 和 `npm run check:contrast`，保留每个问题与无法判定项，不把未覆盖状态称作通过。

主干取景宽度目标从画布的 70% 提高到 85%，目的是减少首屏两侧过宽留白；仍以完整内容和边距为上限，不通过裁切凑比例。与下文 U5 的旧数值冲突时以本段为准。

为了提高淡化内容的文字可读性，模块悬停及未选中项的透明度下限使用 0.8，普通图卡使用 0.8，依赖泳道无关卡使用 0.75；这些值覆盖下文旧版的深度淡化数值，不改变关系或播放步骤。仅用透明度阈值不能保证每个背景都满足对比度，仍需实测。

## U9 引导与入口

顶层能力在当前项目暂不可用时仍保留入口，并用可见原因和下一步说明；相同动作在同一上下文采用一致叫法。视图标题句和首次导览各自只出现一次。首次导览按项目路径保存已读状态，数据类别来自实际识别结果；编号位于对应卡片内部，随画布变换。运行页面入口只调用现有项目连接与会话操作，不自动启动未经确认的开发命令。推荐起点最多三条：前端实际匹配调用计数降序、可证实的只读优先，缺少读写证据时不猜。

推荐条数集中为 `orientation.recommendedLimit=3`：第一屏最多三个选择，避免将完整接口列表重复一遍。数据边使用去重后的读写位置数分三档：0–1、2–9、10以上分别为1.7、2.5、3.5；仅对有实际读写依据的边使用，配置推测边不按读写次数加粗。

本轮只改展示和入口编排；原始值、请求身份、播放步骤、断点与识别结果不变。

唯一令牌源是 `src/shared/ui-tokens.json`。颜色保留深蓝石墨、蓝紫与青色；接收灰、业务紫、数据青、返回琥珀不改变含义。成功、失败和进行中单独用状态色，不借虚线表达三种概念。旧组件颜色迁移到同一源的兼容令牌，避免出现第二套硬编码调色表。

本节覆盖这两个静态阅读视图的外观，不改依赖视图、运行回放和原始识别结果。数值源仍是同一个 `ui-tokens.json`，新增 `hierarchy`、`moduleWidths`、`moduleHeat`、`applicationWidths`、`httpMethod`；不在组件中写项目分支、示意数量或专属坐标。

模块块只实现于 `ModuleBlocks.tsx`，在两视图复用U4的Row；卡面继续使用CardSurface。按路由第一段分组，单模块组并入“其他”，无路径时不造组；组内按接口数量降序。名称去同组共同路径前缀，不能求得路径时用已有代码名去Controller后缀，不写纯数字序号当名称。

热度统计前端调用定义，按唯一已匹配或唯一按路径对上的目标计数，去重同一调用；它不是运行次数。后者的地址仍未确认，线型保留，不补地址。方法条按真实接口方法计数，不把多路径别名重复计成新接口。

模块浮层由一个Provider提供，同屏最多一个；包含完整名称、接口数/前端数和方法分布，不含文件位置或“按Enter打开”。完整名称通过aria-label可访问，截断检查只在真实全局浮层可用的模块按钮上认可该完整名，不给小字或重叠豁免。键盘提示仅在块的焦点位置显示。

资源卡、节点详情与连接详情共用resourceUsage统计：只有源码读写才能写表数/位置数；仅配置发现统一写“只在配置里出现”，卡与线均虚线。默认表名、配置目标等原有依据仍保留在详情；运行高亮只服从实际记录。

## U7 用词与无内容状态

用词与完整句子统一读 `src/shared/ui-wording.json`，规则见 `ui-wording.md`；同一面板同一汇总或名单只出现一次，常驻说明最多三句。资源节点与连线共用ResourceDetails和同一份去重读写/表名单，前端展开不再重复外层汇总；0调用与调用后没有对上分开表达。

未展开方法按实际卡身份计数，折叠组成员不算已经展开；展开沿用原图的渐进显示，不改变原始关系。只有一张实际前端页面卡时保留标准160×44，不采用宽松放大；位置在可用画布上方约三分之一，下面一句真实说明与至多三个其他页面入口。接口调用/引用最多的页面作为默认起点，手动选文件后沿用手动选择。空项目与缺少接口仍沿用R8说明卡。

颜色、字体、行和卡仍用U1/U4；本轮只增加说明宽560px、替代入口宽180px两项令牌。`check:wording`检查工具文案，`--ui`实际核对显示数字与完整明细，`check:layout`继续检查版式。原始值与代码不改写。

## U6 依赖泳道与主辅线

本轮只改变依赖视图的投影与交互表现。索引、真实关系、入口与主干/接口外观保持原义；旧G-v2纵向评分尺子保留，新泳道的实测结果另存，不用旧G数字冒充新画面。

角色共用 `adaptive-look.json` 的 `dependencyRoles`：每行同时保存原appearance、泳道lane和依据，R4的前端角色与U3外观读同一张表。入口、业务、数据、对象、公共依次排列；工具/配置、真实EXTENDS目标基类，或被至少一半可见卡使用的对象进入公共。使用者按不同卡去重，不用重复关系虚增数量。混合职责的旧折叠组保留原代表角色，展开后成员按各自职责落位，不声称包内所有类是同一种角色。

排序、候选路线与种子在 `dependency-policy.json` 的带理由阈值中：总排列≤24（4!）完整评估，超过用四轮重心排序与固定种子640次有界搜索。最初720的精确预算在多关系折叠图耗时约20秒，因此统一降低精确预算，不按项目分支。主线无关重合单独处罚，不能把重合总线写成零交叉；报告同时保留成员交叉和共线区间。最多取可见卡数条主线，多出的关系仍可见为辅线。

初次方向按实际画布宽高比1.4确定，并按项目保存在工具里；后续窗口变化只缩放，不切行列。拖动位置按项目和依赖范围单独保存，沿用稳定id；扩展时已在图中的卡不移动，新卡按所在泳道与父组寻找最近空位。只清理这次投影的过期表现，不写回源码。

关系整理和布局搜索均在Worker；确定位置后先提交同位置骨架，再补边，原卡不会整图清空。验收分别记录主线程>50ms长任务、Worker总时间与骨架帧，不能把后台耗时写成主线程耗时。拖动期间沿用即时连接，停止后按最终位置重走通道。

## U4 版式原件与检查

图卡、入口和方法共用 `Layout.tsx` 的 Row/CardSurface 与 `layout.css`。行采用固定前置槽、至少8字符的文字槽、独立尾槽；单行末尾省略，完整名称放title。副行有独立高度。资源标题与图标同属这一结构，数据标签进入尾槽，不占文字的位置。卡片只保留一层可见底面；依赖卡沿用原走线占位，资源卡按文字度量并限制宽度。

U4令牌覆盖此前相冲突的字号与明暗数值：标题14px、正文12px、标签11px，最小有效字号11px；单行28px、双行44px，内边距12px，资源图标17px，当前描边1.5px。字号随画布缩放补偿，远景进入语义档位或隐藏辅助文字。未涉及节点不透明度至少0.4；不改入返记录、播放推进或动效时序。

取景只围绕当前步骤和一跳邻居，放不下时以当前节点为中心；全貌由用户主动打开。说明卡占独立空间，不能盖住底图文字。`npm run check:layout` 用DOM Range、图标矩形和实际变换后的字号检查；闭合details中未绘制的文字不计可见。画布视口裁切与卡内裁字分别处理。白名单必须逐条写明用途，不能豁免数据标签压字。

- 间距以 8px 为栅格，图标与文字之间可用 4px。
- 圆角：卡片 14px、控件 8px、药丸 999px。
- 字体：12px 次级、13px 正文、15px 标题；代码和原始数据值用 11.5px 等宽，导航与关系标签不用等宽。
- 动效：基础反馈使用120/220/360ms；U2 的数据包、阶段、镜头、呼吸和交错各有专用令牌。完整使用移动与透明度，精简只保留透明度，关闭取消动效；默认跟随系统减少动态效果偏好。每个新操作只对本次涉及节点按已录进入序号入场一次，普通重渲染不重播、不整图淡出淡入。

## 三层信息

L1 常驻只回答“是什么、现在怎样”：图标、名称、一句角色或状态。计数、源码路径、重复所属服务和底部小链接不争夺卡面。服务的模块列表是内部导航，播放时只优先显示本次涉及的模块，其余仍可展开。

L2 是悬停或键盘聚焦后的浮层：计数、文件行号和 Enter 操作。浮层提前保留在 DOM 的独立定位层中，通过透明度和位移显现，不参与卡片排布。Tab 可进入，Enter 打开详情，Esc 收起。不能用仅靠鼠标且延迟不受控的系统 tooltip 代替主要信息。

L3 点击后在既有右侧详情查看数据、源码或关系。返回值、异常、截断和缺失按真实记录呈现；无论入口移动到哪里，都不改值、不猜值。

## 各区域分工

顶部只放项目/视图、当前请求、录制/更多三组。地址与刷新属于页面自己的头部。请求的历史与额外请求在点击后查看；恢复跟随不挤占默认顶栏。

图内展开去掉框套框和行底板。状态点及缩进说明层次；当前步骤的小标记跟随当前行。仅当前经过的关系显示一条短标签，完整值放悬停或数据详情；短标签的省略不修改数据。

底部是一只播放胶囊：操作入口与上展历史、主播放、阶段轨道、步骤摘要、速度。高级动作进入既有更多菜单。走读头只留标题与收起，不再复制阶段条；追踪选择仍在正文工具区。

详情的事实摘要并入头部。方法/数据使用“数据、源码”；浏览器使用“请求、响应、源码”。复制与原始数据放数据段标题右侧，图标有名称、焦点和悬停文字。空章节不占位置，影响判断的缺失与截断仍就地说明。

## 验证边界

报告使用相同真实索引、同一份已有历史、相同尺寸做对比，不制作替代页面。不把静态背景说成实际经过，不把历史截图说成新运行。常驻控件同时报告可点击目标数量与顶栏逻辑分组数，避免将一个三段开关偷算成三个或反过来混口径。

原始色值仅在令牌源中定义。第三方依赖、旧发行物、冻结的 before 和历史验收报告是外部/归档证据，不为了让全目录文本搜索为零而重写；报告必须明确列出这项限制。

## U2 状态动效

所有时长、缓动和状态强度沿用同一令牌文件，不在组件里另写数字。数据标签只取当前边界录到的输入、输出、行数或状态；无数据、无单一端点时不补造。跨单元的运动必须沿已有关系；内部方法短线只连接本单元已有父子。

图库节点的身份、定位层与动画层分离。镜头400ms平移不生成新节点；手动移动后仅暂停镜头，恢复不顺便改变用户的操作跟随偏好。光点、退出视觉层和浮动标签不接管点击。暂停冻结当前进度，跳转可立即接管。

结构展开会引起一次内容布局和受影响区域的尺寸/位移；动效本身仅transform/opacity。验证分别记录世界布局、视觉矩形、视口和DOM身份，不能把微抬、弹簧和镜头运动写成所有屏幕矩形不变。

路径只在几何变化时采样生成CSS keyframes，逐帧不运行JS物理或求解弹簧。静态图不进入旧回放的JS尺寸弹性层；回放状态机与原有播放行为保留。View Transition是浏览器快照而非新图实例，迅速再次选择时跳过旧淡化，让点击立即接管。

用户明确列出的border-color、box-shadow、滑块width是其“三属性”通用条款的列举例外；其余新增动效只修改transform、opacity、stroke-dashoffset。系统 `prefers-reduced-motion` 优先于曾保存的“完整”，全部直接终态，不再只减少位移；显式“关闭”同样无动画。

数值表优先于分镜概述：24块最后一项在23×14+380=702ms完成，不是520ms；12张依赖卡最后一张在11×45+400=895ms完成，1000ms主线完成，主干连线因而从702ms淡入至1102ms；持续两点也不会在900ms静止。截图基于实际内容，不按示意图调整数量、顺序或布局。

## U3 自适应阅读

## 图内叠加层与镜头

线、点、选择轮廓和步骤标记属于画布内容，必须使用同一个视口变换和流坐标；禁止在滚轮回调中测量屏幕坐标并交给React重绘。只有锚点布局改变时更新几何。细亮线屏幕宽度限制1.5–4px，点半径维持现有2.6px；参数集中在overlay/hierarchy令牌中，倒数倍数由store同步写到叠加层局部变量，不向节点分发倍数。粗关系带保持原来的含义和宽度。

屏幕提示在镜头开始移动时立即隐藏，最后一次视口变化120ms后再用elementFromPoint核对鼠标下的对象。模块提示避开块、容器标题和分组标题；上方冲突时先试下方，放不下则不盖住内容。屏幕选择菜单关闭，不留在旧位置。跨原生页面的点击回声不是图内元素，镜头移动时隐藏它的目标轨迹，不能承诺跨进程逐帧同步。

细亮线路径的模块遮罩也在流坐标中：相当于线在模块下层，避免压字；原始路径几何与实际可见交点分别报告。验证使用check:overlay-follow，真实wheel与拖拽输入、五档比例和两种平移，保留端点/逐帧/浮层命中与交叠数据。

## 交互性能预算：滚轮缩放

适用于主干、接口、依赖与运行画布，也约束U5/U6/U7组件。唯一参数源是ui-tokens.json的zoom与adaptive-look.json的分级阈值；不是按项目调参。修改前必须用check:zoom-smooth记录真实窗口输入、每帧比例、提交/节点渲染与Chromium跟踪，然后按原因修，不能用主观“流畅”代替数据。

- 大步滚轮只累计目标倍数，rAF以32ms时间常数指数逼近，120ms收尾；每帧比例变化上限6%。24px内的小增量不增加平滑延迟，下一显示帧直接跟手。像素/行/页系数沿用当前图库，鼠标下同一世界坐标点保持不变；缩放范围取当前画布的实际上下限。
- 视口和节点定位层不使用transform/all的CSS过渡。自动取景/源码定位仍可用原来的有时长镜头；用户滚轮立即用当前视口中断它，再接管。系统减少动态或显式关闭时直接到目标，避免强加镜头运动；这一模式不套用普通模式的100ms插值预算。
- 不向节点分发原始缩放倍数。缩放百分比用现有store的DOM订阅更新，不经过React；相同节点、边及其列表保留身份。自定义节点/边memo，超过30节点使用图库可见项绘制。
- 档位按既有完整/药丸/圆点，进入/退出分别有8%回差，只用120ms透明度切换。字体与轮廓在档位变化或程序取景稳定时更新；同一档内滚轮随画布自然缩放，不每帧改字号，也不在松手时突然换字号。运行时保留当前方法的完整内容，只对既有细节显隐使用回差，不增加播放折叠策略。
- 开始缩放加zooming；停手150ms去掉。期间移除大阴影、滤镜、背景模糊，暂停持续动画，视口用will-change:transform；结束恢复原动画时刻和绘制质量，不改变节点坐标。用户点别处立即接管。
- 普通模式验收：平均≥55fps、p95≤20ms、最大≤50ms、长任务0；滚轮引起提交≤1/事件，节点渲染0，分级变更工作≤8ms；单格至少100ms、单帧≤6%、锚点≤1px，停手200ms内清晰。已有500ms相对时间刷新用测试标记单列，原始总提交保留，不能把它冒充滚轮提交或从原始数据删除。

复跑：在项目根运行 `npm run check:zoom-smooth -- --before` / `npm run check:zoom-smooth`。脚本进程内把临时/缓存目录设到D盘，不改用户全局目录；使用冻结的真实模型和已有历史，不启动目标服务。报告保留原生窗口尺寸、显示器/GPU、计时口径、每个原始事件与rAF、原始总提交/时钟提交/滚轮提交、Layout/Paint/Raster跟踪。输入请求数与浏览器合并后的实际收到数分别列出。

## U3 自适应阅读

静态图的密度、缩放档位、间距和角色表统一在 `src/shared/adaptive-look.json`，每项阈值有理由。宽松卡最多放大1.25倍，六至十五卡保持标准尺寸；超过预算或单卡超过八模块使用紧凑呈现。模块瓦片保留每个真实模块，按接口数排列，悬停和聚焦显示全名，点击仍进入原来的接口分支。
