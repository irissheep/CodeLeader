# 界面用词表

界面讲读者正在看的对象与事实。实际源码、接口、SQL、文件位置和录到的值原样保留；下表约束工具自己写的话，不修改项目内容。

| 规则 | 写法 | 原因 |
|---|---|---|
| 每块至多3句 | 一句事实、一句缺项、一句下一步；没有缺项就不补说明 | 先看内容，再按需查看来源 |
| 一事一次 | 同一面板的同一汇总、名单只出现一次；名单折叠，汇总与明细共用数据 | 不让相同数字抢占阅读空间 |
| 每行说对象 | 读「表名」表、调用「方法名」、打开「页面名」 | 不用只有“读取”“代码”的空泛动词 |
| 来源 | 替换工具文案中的“依据” | 清楚说明信息从哪来 |
| 环境设置 | 替换“profile” | 真实配置键与源码内容仍保留 |
| 分析结果 / 更新分析 | 替换工具自述中的“索引” | 不把后台实现名当作读者任务 |
| 还不能确定 / 有几种可能 | 替换“候选” | 保留不确定性，不伪装唯一结果 |
| 还没展开的方法 | 替换“追踪边界”“尚未展开 / 当前范围外” | 显示对象、数量与展开操作 |
| 分析还没跑完，下面的流程可能不全 | 替换“部分索引完成”等解释句 | 一句交代影响，不重复免责声明 |
| 这份配置默认没启用 | 替换未启用环境的实现说明 | 仅在配置确有此事实时显示 |
| 只在配置里出现 | 替换“本轮支持”“静态配置与源码事实”“不连成必经流程”等自述 | 未找到访问位置时准确说明范围 |
| 没读取其他环境的设置 | 替换“未合并” | 不将配置中的资源说成已运行 |
| 这个页面不调接口 | 页面关联调用数确为0 | 与“调用了但没对上后端”区分 |
| 这个页面没有引入别的文件，也没有调用接口 | 当前文件依赖和页面调用都为0 | 单卡不放大，提供可打开的其他页面 |
| 换一个看看 | 最多3个调用最多的真实页面 | 不造页面、数字或空壳卡 |

禁用词与扫描边界集中在 `ui-wording-policy.json`。可复跑 `npm run check:wording`；文字串、标题、提示、无障碍名称和生成说明都检查。程序属性名、正则、原始源码和值不属于界面措辞，不能为通过检查改写它们。

汇总核对按明确的对象标记执行：前端调用总数等于其完整调用明细，已对上与未对上的分区之和等于调用数；页面为0时不能说“未对上”；资源表数与读写位置数从同一份去重关系得到；方法未展开数量按不同下游目标去重，折叠卡中的成员不算已展开。重复来源用位置和说明去重，表名单独折叠只出现一次。

默认从接口调用数与项目内文件引用数之和最多的页面开始；并列时比较调用数、名称与稳定身份。手动选择文件时保留选择。“换一个看看”按调用数排序，同一组件的路径别名只占一个入口；不足三个时不补造。

`src/shared/ui-wording.json` 是替换词、完整句子、设置名称和少量阅读预算的唯一表；组件只按当前事实选择适用句子，不按项目名称分支。旧历史中的工具说明可用同表换写，原始错误记录、源码、SQL、地址、录到的入参与返回值不做措辞替换。

复跑真实窗口的汇总核对与五类截图：`npm run check:wording -- --ui --review-config=tests/fixtures/u7-review.json`。没有对应资源、前端或方法的项目记录不适用，并保留实际画面，不伪造面板。
